# Go Customer Reports

PHP marketing and advertorial landing pages. Each subdirectory contains a campaign or set of page variants (Customer Reports, Evergreen Botanicals, Electric Eye, QR pages).

## Status
Pre-revenue. 31,435 LOC, 63 commits.

## Tech Stack
- Plain PHP 7.4
- Bootstrap 5.3.0, jQuery 3.6.0, Fancybox (all CDN)
- Google Tag Manager

## Local URL
`http://localhost/go-customer-reports/`

## GitHub
`themikekeating/go-customer-reports`

## Connections
- Leads flow to **Portal** via tracking links
- Shares templates across campaigns via `tmp/` directory
